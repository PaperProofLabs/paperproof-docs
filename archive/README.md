# archive

This directory is reserved for archived PaperProof materials.

Typical contents may include deprecated drafts, superseded branding, earlier
whitepaper versions, old diagrams, retired screenshots, abandoned directions,
and other historical materials that remain useful as project records but are no
longer current working assets.

Current substantive records are not stored here yet. Use these active locations
instead:

- [../artifacts/](../artifacts/) for publishing checkpoints, Walrus extension
  records, and flagship-material version records.
- [../screenshots/](../screenshots/) for current website and public-facing
  evidence screenshots.
- [../overflow2026/](../overflow2026/) for Sui Overflow 2026 research and
  submission-support records.
