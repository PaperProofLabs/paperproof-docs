# governance

This directory is reserved for PaperProof governance materials.

Typical contents may include governance-route notes, operator succession models,
committee documentation, authority-boundary explanations, governance diagrams,
and policy-oriented materials that describe how governance is organized or
presented within the PaperProof ecosystem.

Current substantive governance material lives in:

- [../homepages/docs/governance-and-economics/](../homepages/docs/governance-and-economics/)
  for user-facing governance, fee, sustainability, and PPRF utility docs.
- [../legal/official-discretion-and-change-policy.md](../legal/official-discretion-and-change-policy.md)
  for official-interface change and discretion boundaries.
- [../legal/identity-and-role-separation.md](../legal/identity-and-role-separation.md)
  for protocol/team/user role separation.
- [PaperProofLabs/paperproof-contracts](https://github.com/PaperProofLabs/paperproof-contracts)
  for governance-relevant protocol package implementation.
