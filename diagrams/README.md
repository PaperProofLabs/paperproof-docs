# diagrams

This directory is reserved for PaperProof diagrams and structured figures.

Typical contents may include architecture diagrams, workflow figures,
verification diagrams, governance diagrams, contract-model figures, deployment
figures, sequence diagrams, and other visual explanations used across
whitepapers, documentation, or presentations.

Current substantive diagram sources and rendered assets live in:

- [../homepages/blogs/figures/tikz/](../homepages/blogs/figures/tikz/) for the
  TikZ source of blog and architecture figures.
- [../homepages/blogs/assets/](../homepages/blogs/assets/) for rendered SVG,
  PNG, and PDF figure assets.
- [../homepages/docs/assets/application-architecture-flow.svg](../homepages/docs/assets/application-architecture-flow.svg)
  for the Docs version of the application architecture figure.

The same architecture figure family is also reused by the papers and slides
repositories when preparing official submissions and presentations.
