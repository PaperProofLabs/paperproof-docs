# did

This directory is reserved for DID-related materials associated with the
PaperProof ecosystem.

Typical contents may include DID method drafts, naming discussions, protocol
specification materials, comparison notes, registration-oriented drafts,
reference materials, and supporting records related to decentralized identifier
work.

DID-specific work is not a primary live workstream in this repository yet. The
current durable-identity material is expressed through PaperProof artifact
identity and canonical-state documentation:

- [../homepages/docs/protocol/artifact-model.md](../homepages/docs/protocol/artifact-model.md)
  explains stable artifact identity on Sui.
- [../homepages/docs/protocol/manifests-and-canonical-state.md](../homepages/docs/protocol/manifests-and-canonical-state.md)
  explains manifests, hashes, blob references, and canonical state.
- [PaperProofLabs/paperproof-contracts](https://github.com/PaperProofLabs/paperproof-contracts)
  contains the Sui contract implementation that anchors these identities.
