# whitepaper

This directory is reserved for PaperProof whitepapers and closely related
materials.

Typical contents may include LaTeX sources, compiled PDFs, figures, captions,
appendices, revision notes, and supporting materials used to explain the
PaperProof protocol, architecture, governance, token design, or ecosystem
positioning.

Current substantive paper material lives in:

- [PaperProofLabs/paperproof-papers](https://github.com/PaperProofLabs/paperproof-papers)
  for the white paper, yellow paper, academic paper, LaTeX sources, figures,
  and compiled PDFs.
- [PaperProofLabs/paperproof-slides](https://github.com/PaperProofLabs/paperproof-slides)
  for the technical report / presentation deck.
- [../homepages/blogs/assets/application-architecture-flow.svg](../homepages/blogs/assets/application-architecture-flow.svg)
  for the application architecture figure reused by the papers and slides.
