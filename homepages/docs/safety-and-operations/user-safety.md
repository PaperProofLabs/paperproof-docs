PaperProof records durable protocol facts. Users remain responsible for
reviewing content, wallet prompts, and external links.

## Before signing

Review:

- wallet address;
- network;
- object IDs;
- transaction purpose;
- token amounts;
- gas;
- locked voting funds;
- storage operations;
- external links.

## Never share secrets

Do not provide:

- private keys;
- seed phrases;
- wallet recovery phrases;
- confidential credentials;
- model API keys in public content;
- MemWal access material in public content.

## Copilot boundary

Copilot is a guidance tool. It may explain protocol state and workflows, but it
does not sign, approve, custody assets, guarantee correctness, or replace user
review.

## Content boundary

Displaying an artifact does not mean PaperProof Labs created, reviewed,
approved, verified, endorsed, or recommends its content.

## Durable publication requires care

Publishing to a durable public system has consequences. Before uploading,
confirm that you have the right to publish the content and that the package does
not expose secrets, private personal data, confidential documents, embedded
credentials, or unsafe executable material.

An interface may later stop displaying content, but non-display is not a
guaranteed deletion mechanism for Sui records, Walrus blobs, external caches,
or third-party indexers.

## Verify before relying

When the stakes are higher than casual browsing:

1. Confirm the artifact series ID and exact version.
2. Retrieve the referenced content.
3. Verify the content hash.
4. Review the source, authorship claims, and context independently.
5. Treat comments and likes as discussion and signals, not certification.

## Agent Memory safety

Agent Memory reduces public exposure by keeping private bodies outside
PaperProof Move objects. It does not remove every privacy risk. Do not ask
Copilot to retain passwords, recovery phrases, private keys, confidential
credentials, or sensitive personal records. Browser storage, relayer handling,
provider policy, and device security still matter.
