PaperProof governance provides an auditable path for protocol evolution.
Economics should support useful participation, spam resistance, and sustainable
maintenance without making unrealistic promises.

PPRF is a governance and participation asset. It is not a guarantee of revenue,
yield, liquidity, market value, or artifact quality.

PaperProof separates protocol legitimacy, operational execution, and economic
interpretation. Token voting is appropriate for durable protocol decisions.
Bounded active-operator actions are appropriate for routine maintenance such as
updating an official prompt route or disabling an Agent Memory entry.
