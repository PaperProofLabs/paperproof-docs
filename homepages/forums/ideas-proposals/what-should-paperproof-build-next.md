# What Should PaperProof Build Next?

Author: PaperProof Labs  
Category: Ideas & Proposals  

This starter topic is for product ideas, protocol extensions, ecosystem
experiments, and future application directions.

PaperProof already has the foundations for versioned artifacts, Walrus content
references, official comments and likes, SDKs, a reference indexer, native
Copilot prompts, Agent Memory registration, official Docs, and official Blog
content. The next question is where these primitives should be applied first.

Possible directions include:

- richer Blog and Forum pages using protocol-native artifacts;
- better official topic discovery and pinned manifests;
- a public API backed by the reference indexer;
- more examples for research papers, datasets, and software releases;
- stronger Copilot guidance around publishing and verification;
- agent-generated reports that become PaperProof artifacts;
- independent demo apps that show PaperProof as reusable infrastructure.

Useful questions for this board include:

- Which use case would make PaperProof easiest to understand for new users?
- Which use case best demonstrates value to the Sui and Walrus ecosystems?
- Which features are needed before broader community onboarding?
- Which integrations would help developers build independent interfaces?
- Which workflows should remain simple rather than over-governed?

Ideas here should be concrete when possible. A good proposal names the target
user, the current pain point, the PaperProof primitive involved, and the
smallest useful implementation.
