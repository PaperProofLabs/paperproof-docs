# Welcome to the PaperProof Community Forum

Author: PaperProof Labs  
Category: General  

Welcome to the PaperProof community forum.

PaperProof is a protocol and application stack for verifiable knowledge
artifacts. It combines Sui object state, Walrus content storage, official
comments and likes, SDKs, a reference indexer, protocol-native Copilot prompts,
and optional wallet-linked Agent Memory.

This forum is intended to be practical. It is a place for questions, feedback,
early user reports, integration notes, use-case discussion, and thoughtful
critique. The first official topics are themselves PaperProof artifacts, so the
forum can demonstrate the same protocol model it discusses.

Good community posts should try to be specific:

- describe the use case or issue;
- include object IDs, artifact codes, or transaction digests when relevant;
- separate confirmed behavior from assumptions;
- avoid sharing private keys, seed phrases, or sensitive personal information;
- remember that displaying an artifact does not mean PaperProof Labs has
  reviewed, endorsed, or guaranteed the content.

PaperProof is still early. The most useful discussion will help turn working
infrastructure into a clearer product, a stronger protocol, and a more useful
knowledge layer for humans and agents.
