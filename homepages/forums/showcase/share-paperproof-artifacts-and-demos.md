# Share PaperProof Artifacts and Demos

Author: PaperProof Labs  
Category: Showcase  

This starter topic is for sharing artifacts, demos, papers, datasets, software
releases, public builds, and other work that uses PaperProof or relates to
verifiable knowledge infrastructure.

PaperProof is designed to support many artifact families. A showcase item may
be a research note, a technical report, a dataset snapshot, a software release,
a Blog post, a forum topic, a prompt package, or a demo application. The common
thread is durable identity, version history, content references, and
inspectable protocol state.

When sharing a work, useful details include:

- artifact code or series ID;
- latest version ID;
- content type and Walrus reference if relevant;
- what problem the work demonstrates;
- whether the work is official, experimental, third-party, or personal;
- what feedback would be most helpful.

The official interface may choose what to highlight, pin, or curate, but the
protocol itself can be used by independent builders. This board is a place to
make useful work easier to discover without treating every shared artifact as
an endorsement by PaperProof Labs.

For early demos, clarity matters more than polish. Explain what the artifact
proves, what is still experimental, and how another user can inspect the
underlying record.
